# Personal settings

Copy this file to `~/.claude/wow-config.md` (`install.sh` does it for you) and fill it in. Every skill reads it at the start of a run. It stays on your machine.

- **Name:**
- **Chat language:** the language you want in chat. Files are always written in English.
- **Background:** what you already know well, so new things get explained from it. Example: TypeScript, React, the browser.
- **How I learn best:** for example, a diagram for every mechanism, the bad version before the good one.
- **Who does the work:** `guided` (I run every command and write the code; the AI explains the why before each step and gives one step at a time) or `delegated` (the AI writes, I review line by line). See "Who does the work" in `SKILLS.md`.
- **Impact log:** `~/impact-log.md`
- **Career tracker:** where you keep evidence of your skills (a brag document, a skills matrix), if you have one.
- **Lessons file:** a file that says where each concept from the pages is explained in your own learning material, if you have one. Shape: one `### <page>` heading per page, then `- <concept> → <link>`.
